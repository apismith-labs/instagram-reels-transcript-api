## What's New

The v0.10.0 repository release adds the Java 17 SDK and command-line examples to the existing
Python, Node.js, and Go integrations for the Apify Actor
`apple_yang/instagram-transcripts-scraper`. This repository contains integration examples; it is
not a hosted transcription service.

## Supported Language Examples

- **Python** — reusable Single URL, Native Bulk, Profile post metadata, and CSV Batch examples.
- **Node.js** — reusable client functions and Single URL, Native Bulk, Profile metadata, and CSV
  Batch CLIs.
- **Go** — Go 1.22+ reusable module with Single URL, Native Bulk, Profile metadata, CSV Batch, and
  journal-backed Single/Bulk Resume.
- **Java** — Java 17 reusable SDK and CLI for Single URL, Native Bulk, Profile metadata, CSV Batch,
  and GET-only Single/Bulk Resume.

These examples do not have identical feature sets or Live coverage. Rust remains experimental and
is outside this release's supported-language scope.

## Java 0.1.0 and Repository v0.10.0

`v0.10.0` is the root repository version. The Java Maven project has its own version, `0.1.0`, and
is not published to Maven Central. If included in this release, the Java 17 Shaded JAR is named
`instagram-reels-transcript-api-java-examples-0.1.0-shaded.jar`; its filename identifies the Java artifact
version rather than the root Git tag. See [the Java Quick Start](../../examples/java/RELEASE-QUICKSTART.md)
and [Java guide](../../examples/java/README.md).

The Go module is versioned with a nested module tag in addition to the root repository tag. Use a
versioned `go get` only after the matching nested module tag for this release has been published and
verified.

## Features and Safety

- Java adds a reusable SDK and CLI for Single URL transcripts, one-Run Native Bulk, Profile post
  metadata, CSV planning and explicit execution, and journal-backed Single/Bulk Resume.
- Java pins Actor Build `0.0.50` and verifies the returned Build identity before accepting Dataset
  results. Run creation uses one POST attempt, does not follow redirects, and is not automatically
  retried; uncertain creation requires reconciliation.
- Java CSV is plan-only by default. `--execute` requires a positive per-Run charge cap. Journal
  intent is persisted before creation, and Resume is GET-only.
- Go and Java support the documented journal-backed Resume flows. Other languages expose the
  recovery behavior documented in their individual guides.
- Profile modes return post metadata, not transcripts. Dataset reading is bounded and incomplete
  results are handled conservatively where implemented.
- `maxTotalChargeUsd` is a per-Run platform option. It is not a guarantee of the final account bill
  or a total CSV-batch spending ceiling.

## Verification

- Java offline suite: 142/142 JUnit executions passed; mutation checks detected 4/4 expected
  regressions. The Java 17 GitHub Actions workflow also builds thin and shaded JARs and compiles and
  runs an external consumer against the newly built Shaded JAR.
- Python, Node.js, and Go have offline CI workflows. Confirm the main-branch runs for the exact
  release commit before publishing this Release; branch CI results are not substitutes.
- Controlled Live acceptance covers selected Python, Node.js, Go, and Java scenarios on Actor Build
  `0.0.50`. These narrow checks do not establish broad production reliability or arbitrary-input
  success.
- Java Live acceptance: L1 Single URL, L2 three-URL Native Bulk, L4 one-row CSV, and L5 GET-only
  Single Resume passed. L3 three-account Profile was **PARTIAL**: 19 posts succeeded, one post had
  unknown owner attribution, and one account returned Actor error `crawed empty`.

## Known Limitations

- Java Profile L3 remains **PARTIAL**; the result reflects the Actor's original items. The Java
  implementation does not rewrite or conceal the source Actor data.
- Python CSV execution has not had Live acceptance. Node.js Profile and CSV did not receive new
  Live acceptance in this release cycle.
- Go Live checks cover only the documented small inputs. General pagination, arbitrary Bulk sizes,
  mixed failures, and every recovery path remain unverified.
- Java multi-row CSV, mixed-failure Bulk, 100-item Dataset boundaries, and recovery from a genuinely
  ambiguous Run-creation outcome remain unverified.
- Profile Resume is not implemented. Go and Java CSV Resume are not implemented. Java is not
  available from Maven Central.
- A successful controlled Run does not prove long-term production stability, success for every
  account or URL, or behavior across all regions and failure conditions.

## Installation / Quick Start

Clone the repository and follow the guide for your language:

```sh
git clone https://github.com/apismith-labs/instagram-reels-transcript-api.git
cd instagram-reels-transcript-api
```

- [Python](../../examples/python/README.md)
- [Node.js](../../examples/nodejs/README.md)
- [Go](../../examples/go/README.md)
- [Java 17 Shaded JAR Quick Start](../../examples/java/RELEASE-QUICKSTART.md)

For Java, download the Shaded JAR and `SHA256SUMS.txt`, verify the checksum, then run the
no-network `--version` and `--help` checks before configuring credentials. A real request may
create a billable Actor Run.

## Upgrade Notes

This is a root repository release, not one shared package version across all languages. Python is
distributed as source examples, the Node.js package metadata is private example metadata, Go has a
nested module version tag, and Java remains a separately versioned `0.1.0` Maven example. Review the
language-specific installation guide before upgrading. Do not infer Maven Central availability or
Go module publication from the root Git tag alone.
